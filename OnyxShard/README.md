# OnyxShard (Paper 1.21.11)

## Compiler
Java 21 + Maven requis :

    mvn clean package

Le plugin se trouve dans `target/OnyxShard-1.0.0.jar` → à mettre dans `plugins/` du serveur Paper 1.21.11.

## Commandes
- `/shop` : boutique des pouvoirs permanents
- `/dropshard <nombre>` : dépose des ONYX SHARD au sol
- `/sold` : affiche le solde

Données : `plugins/OnyxShard/data.yml`  |  Config : `plugins/OnyxShard/config.yml`
